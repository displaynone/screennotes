# ScreenNotes icon

The mark combines an open capture frame with a solid pencil silhouette. It uses thick shapes and no lettering, shadows, or gradients so it remains recognizable at small sizes.

- `screennotes.svg`: primary app icon, white on indigo (`#5458E8`).
- `screennotes-symbolic.svg`: transparent monochrome icon for the Ubuntu top bar. Its tighter view box keeps the mark readable at 16 pixels.
- `previews/screennotes-*.png`: PNG exports from 16 to 512 pixels.
- `previews/logo-preview.png`: overview with actual-size icons and the monochrome variant.

Use the SVGs as the source artwork. Preserve their proportions and padding. The indicator includes a matching raster fallback for environments that cannot resolve the symbolic icon.
